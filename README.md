## 🧩 Projects (selected)

- Disease X Command Center — Streamlit, PostgreSQL, Supabase, Machine Learning (Aug 2025)  
  Built a real-time full-stack hospital management dashboard using Streamlit and Supabase for live data ingestion and patient triage; designed actionable insights to reduce manual triage effort.

- Resume Analyzer — Python, Streamlit, Scikit-Learn, TF-IDF, MiniBatch K-Means (Dec 2025)  
  Built an unsupervised ML pipeline using TF-IDF + MiniBatch K-Means to cluster unlabeled resume entries; added a confidence-based fallback and rule-based keyword classifier to route ambiguous resumes to human review. Live demo & PDF parsing on Streamlit.

- UpFeed — News Aggregator (May 2026)  
  Responsive news aggregator integrating GNews API and NewsAPI; React.js frontend with category-based filtering and reusable components.

- IthaisaAI — Indian History Chatbot (June 2026)  
  Fine-tuned Llama 3 8B Instruct using UnsLoTh quantization and built a RAG-backed chatbot with streaming chat UI and prompt-engineered retrieval-augmented generation for historical context.

- AI IDE — Browser-Based Code Editor (July 2026)  
  Deployed a full-stack, browser-based IDE with AI-assisted code generation and live interactive terminal using React + FastAPI; sandboxed multi-language code execution on AWS EC2 with Nginx, Let's Encrypt, and Supabase auth.
